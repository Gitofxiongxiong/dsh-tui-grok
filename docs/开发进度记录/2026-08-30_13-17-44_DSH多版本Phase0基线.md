## 风险、回滚和依赖

- 风险：检查脚本若把 source-only 误解为可从 npm 解析，会与当前 alpha.1 runtime 现实冲突。
- 缓解：脚本只验证 manifest 中精确 DSH 版本必须存在于 registry，并报告其 `distribution`；不执行 npm 网络可用性门禁（属于 Phase 6）。
- 风险：上游 checkout 路径是机器特有数据。
- 缓解：路径仅通过环境变量注入，不写入 support registry；未注入时输出具体 skip 原因。
- 回滚：单独 revert 本批 commit，删除新增 registry、说明、脚本和清单；运行时不受影响。
- 依赖：Node.js 内建模块与 Git CLI，不增加 npm 依赖。
