# Prompt 模型与模式标签原子裁剪

## 目标与背景

Hello/空会话页面横向 resize 跨过 prompt 底边信息行的列宽阈值时，
当前整行裁剪会把语义标签拆成“准模式”或“YOL”。真实长模型名
`DeepSeek-V4-Flash-Vision-Exp` 又使该问题在常见窄宽度更容易触发。

本批将 V4 Flash 家族的 prompt 展示名收敛为用户指定的 `dsv4 flash`，
并使 preset/plan/YOLO 成为不可拆分的显示单元：宽度不足时先收缩或
隐藏模型名，不在标签中间硬裁。Hello 紧凑页同样只裁模型名，保留
完整 preset。

- 风险：CJK 字符占两列；所有 budget 使用 Unicode display width，测试必须
  包含中文 preset。

- 预期验证：相关 Rust 单测、crate lib tests、fmt/diff check、ttyd+xterm.js+

## 实际修改

- `crates/dsh-pager-grok-ui/src/model_state.rs`
  - 新增纯展示投影 `compact_model_label`；仅把名称同时含有
    `deepseek`、`v4`、`flash` token 的模型显示为 `dsv4 flash`。
  - catalog name、`ModelId`、picker 和 RPC payload 均未改变。
- `crates/dsh-pager-grok-ui/src/runtime.rs`
  - prompt 底边和 welcome surface 都通过同一个 compact model label 投影，
    不再由两个表面各自处理长模型名。
- `crates/dsh-pager-grok-ui/src/views/prompt_widget.rs`
  - 用 `fit_info_line` 代替整行按列硬裁：从右向左选择能够完整放下的 flag，
    再将剩余列分配给中间省略的 model。
  - preset/plan/YOLO 与 usage warning 都只完整显示或整个省略；省略 flag 返回
    空 hit rect，完整 flag 的点击宽度与 Unicode display width 一致。
- `crates/dsh-pager-grok-ui/src/views/welcome.rs`
  - compact welcome 行优先保留完整 preset；仅 model 允许中间省略。preset 本身
    也放不下时整个省略，不再把 `标准模式` 裁成 `准模式`。
- 没有修改 vendor、source manifest、协议或用户已有未提交文件。
