## 目标与背景

上一批已把 DeepSeek V4 Flash 家族在 prompt/welcome 紧凑位置显示为
`dsv4 flash`。实际 catalog 中以 `DeepSeek-V4-Flash` 开头的模型有两个，
并且 Pro 模型也需要对应的短显示名 `dsv4 pro`。

用户进一步要求改为项目内文件形式的精确映射表，并支持双击模型名打开现有
模型选择弹窗。本批因此收敛为数据驱动规则：

- 映射表命中 -> 使用配置的短名；
- 未命中 -> 保留 Host 原名，由 prompt/welcome 按实际可用列中间省略；
- prompt 和 Hello/welcome 上实际画出的模型文字均返回同源 hit rect；
- 同一模型 hit rect 在 450ms 内双击 -> 打开已有 `/model` picker。

首批映射为 `DeepSeek-V4-Flash` -> `dsv4 flash`、Vision Exp/Preview ->
`dsv4 flash-v`、`DeepSeek-V4-Pro` -> `dsv4 pro`。

只修改 prompt/welcome 已使用的展示投影，不改 catalog、picker、模型 ID 或 RPC。

## 风险、回滚和验证

- 风险：映射文件格式错误；使用随二进制编译的 JSON、解析单测和唯一键检查，
  不读取用户目录或静默改写 Host 数据。
- 映射匹配大小写不敏感，但必须保留非目标名称原样；显示层负责按列省略。
- 风险：prompt 整体 hit rect 会覆盖模型文字；模型 rect 使用更高 overlay priority，
  且必须来自 paint-time geometry，避免 resize 后错点。
- 回滚：回滚本记录对应单一提交；无数据迁移。
- 验证：映射表/model_state 定向单测、prompt/welcome geometry 与双击判定单测、UI
  crate 全量测试、workspace check、rustfmt/diff check，以及 ttyd/xterm.js/
  Playwright 真实 catalog、缩放和鼠标双击回归。

## 实际修改

- `crates/dsh-pager-grok-ui/model-label-aliases.json`
  - 新增项目内 JSON 映射表：Flash -> `dsv4 flash`、Vision Exp/Preview ->
    `dsv4 flash-v`、Pro -> `dsv4 pro`。
- `crates/dsh-pager-grok-ui/src/model_state.rs`
  - 通过 `include_str!` 编译映射表并以大小写不敏感的精确名称查找；未知名称
    原样返回，不再使用过宽的 token/前缀猜测。
  - JSON 非 string-to-string object 时 fail fast；单测覆盖空值和大小写归一后的
    唯一键。
- `crates/dsh-pager-grok-ui/src/views/prompt_widget.rs`
  - prompt info fitter 除 flag rect 外返回实际画出的 model rect；未映射长名称仍由
    同一 fitter 按实际剩余列中间省略。
- `crates/dsh-pager-grok-ui/src/views/welcome.rs`
  - wide/compact welcome 都返回 paint-time model rect；wide 未映射名称也先按模型
    value 的可用列中间省略，不再依赖 Buffer 硬裁。
- `crates/dsh-pager-grok-ui/src/runtime.rs`
  - prompt 与 Hello 的 model rect 注册为高于底层 prompt/scrollback 的 hit region；
    450ms 内第二次左键点击复用现有 `open_model_picker`，首次点击只给出提示。
  - resize 清除未完成的模型双击状态，避免旧几何上的第二次点击误触发。
- 未改 model catalog、picker row、ModelId、RPC payload 或 vendor；用户已有未提交
  文件保持不动。
