## 目标与背景

- CLI 源码可保留 `workspace:*`；打包必须改写成精确版本（pnpm pack）。

## 实际文件与摘要

- B4：CLI 单测不再依赖 gitignore 的 native 二进制；缺二进制时仍断言
  `DSH_PAGER_BIN` 不会在无 `DSH_PAGER_DEV_MODE` 时生效。
- I11：`dsh-pager update` 一律走 `ensureProfileBundle()`，检查 plugin 状态。
- I12：doctor 对无法解析/缺失的私有 DSH、`dump-config` spawn error 设 hardFail。
- I13：`reconnect()` 转移旧 stderr tail 与 failed 标记；unknown response /
  unexpected frame `mark_failed`。spawn 单测覆盖 reconnect 保留 tail。
- I14：`scripts/verify-cli-pack.mjs` 用 vendored `pnpm pack` 断言无 `workspace:*`、
  runtime 为 `0.1.0`；`verify:ts` 纳入该脚本。
- I15：未知 flag / 缺值改为 `UsageError`（exit 2）；leaf 命令拒绝多余参数。
- 建议：runtime/CLI 打包带 LICENSE-MIT/APACHE/NOTICE；stdio write error 走
  `onWriteError` 并停止后续写（输入 close 后仍允许诊断 notify）。
