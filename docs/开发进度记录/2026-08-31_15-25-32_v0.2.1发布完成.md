## 风险、回滚和依赖

- 风险：registry CDN 缓存造成 dist-tag 误判。控制：写入后使用官方源
  `--prefer-online` 重试，并在全部提升后逐包重新读取 metadata。
- 风险：浏览器二次验证只绑定单个写请求。控制：五个 native、runtime、CLI 严格
  串行，维护者逐页确认，每个返回 `+latest` 后再进入下一项。
- 风险：Release 指向错误 Tag。控制：使用 `gh release create --verify-tag`，随后读取
  Release 与 peeled Tag/远端 main commit 交叉核验。
- 回滚：本记录可由后续文档 PR 更正；若公开版本出现真实缺陷，只把 `latest` 回退到
  最后已知良好版本，不覆盖或删除 `0.2.1`。
- 依赖：GitHub CLI 与 npm 官方源账号已登录；正式 publish 仅通过 GitHub OIDC。
