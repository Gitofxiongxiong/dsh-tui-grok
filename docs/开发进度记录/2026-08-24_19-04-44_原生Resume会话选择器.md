# 原生 Resume 会话选择器

## 目标与背景

当前默认 TUI 在空 prompt 下用裸 `p` 打开一个 DSH 通用 picker；它的标题、tabs、
行模型、搜索、展开和 footer 均不等同于 Grok Build 的 `/resume`。本批把入口改为
本地 `/resume` slash command，并移植 Grok 原生 session picker 的 native-only
视觉和交互闭包。DSH 继续拥有 session.list/session.search、稳定 session id、
generation 和加载屏障。

## 风险、回滚和依赖

- 风险：DSH session.list 字段少于 Grok，展开卡片只能显示真实存在的 ID/CWD/
  Model/Updated；不得伪造 Created/Messages/Recap。
- 风险：attach loader 仍是同步屏障，选择后短时间内 TUI 可能暂停；保持现有可靠
  barrier，并在状态栏明确显示 attaching。
- 风险：repo header 是非选择行，render 和 input 必须共享同一 index map。
- 回滚：删除本批新增的两个 vendored closure 和 slash seam，恢复 app/runtime
  的旧 picker 分支；协议和 host 数据不需要迁移。
- 依赖：只使用现有 workspace crate，不增加 Grok runtime 或新第三方依赖。
