## 目标与背景

用户实测发现当前 `/` 菜单贴在终端最左侧、只有三行裸命令，且 `/model`
不能继续展示和选择真实模型。只读诊断已确认真实 DSH profile 的
`session.models` 能返回 3 个 DeepSeek 模型及各自 4 档 reasoning effort，问题位于
TUI 的自建 suggestion renderer/controller 和 Enter/Esc 事件优先级，不在 Harness。

本批按用户要求以 `/home/leo/aidreamschool/grok-build` 为 UI/交互真源：能直接复制
的代码直接复制，不创建平行视觉组件；DSH 只保留模型目录和
`session.selectModel` effect 适配。

## 实际修改

- 固定新增 Grok 使用的 `nucleo` git rev `5b74652`，直接复制
  `slash/matcher.rs`；匹配、排序、模糊高亮不再由 DSH 自造。
- 直接复制 Grok `views/slash_dropdown.rs`、`render/safe_buf.rs` 并通过 path module
  接入。仅有两处 A1 seam：DSH 只面向现代终端，固定使用 Grok 对应的 `❯ `；DSH
  没有 Grok 的进程级 bidi 开关，因此 safe bidi 路径保持逻辑顺序。
- 以 Grok `slash/mod.rs` 为真源重建 `src/slash.rs`：保留命令/参数两阶段、选择保持、
  wrap/page 移动、范围替换、模糊排序和 exact-command Enter 契约；只注入 DSH 已拥有的
  `/resume`、`/preset`、`/new`、`/model`、`/timestamps` 及 Host 建议。
- 复制 Grok AgentView 的 dropdown chrome/inset/width 几何，菜单覆盖层与 prompt 使用同一
  outer padding；删除自建 `views/suggestion_controller.rs`，不保留第二套 renderer/state。
- `runtime.rs` 改为 slash-first 按键路由和覆盖层绘制；`/model` 接受后从真实
  `session.models` 展示模型，推理模型继续进入 effort 阶段，最终复用既有
  `session.selectModel` effect。补回 Grok 参数占位 ghost：`/model <model> [effort]`。
- `SOURCE_MANIFEST.md` 新增本批复制/抽取条目与散列；同时校正一个早已存在但未回写的
  `session_picker.rs` local hash，manifest 门禁恢复为零 drift。
