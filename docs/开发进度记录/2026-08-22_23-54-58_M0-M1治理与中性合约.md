## 实际修改

- M0 治理：固定 `main` Git 根后的第二批工作范围；增加 `scripts/check-source-manifest.py`，分别报告 local hash drift、upstream drift、缺失 license；更新 `SOURCE_MANIFEST.md` 为 upstream/vendored 双 hash 并记录更新时间；增加 `scripts/baseline.sh` 和 `docs/M0_BASELINE.md`；将 all-features clippy 的 ratatui Backend 新 trait 方法、markdown fixture 缺口和 vendor test needless-borrow 处理在 wrapper/test fixture 边界，未修改 vendor 文件；增加八个 parity 输入 fixture、80x24/40x12 fallback semantic baseline、冻结 fallback 注释。
- M1 identity/projection：新增 `DshSessionId`、`DshRequestId`、`DshGeneration`、`DshSeq`、`DshQueueItemId`、`DshInteractionId` newtype；`DshRenderEntry` 保留结构化 blocks、partial、lineage；scrollback 透传这些字段并保持快照兼容。
- M1 host snapshot：`GrokHostSnapshot` 分区包含 session header、agent view、prompt metadata、rich transcript、queue/revision、interaction、diagnostics、roster stable id、capability matrix；prompt draft 明确为 local/non-authoritative。
- M1 effects：将旧 `UiEffectSink::dispatch(effect, SessionState)` 改为 `UiIntent -> UiEffect -> UiEffectReceipt`，trait 只接收 `UiIntent + UiContext`；支持 submit/attach/queue mutation/interaction response/rename/fork/archive；receipt 覆盖 accepted/rejected/stale/conflict/unsupported/failed 等状态；operation key 带 generation/request/action/dedupe key，concrete DSH sink 对已完成 operation 去重。
- M1 tests：增加 identity、deterministic rich host snapshot、capability projection、neutral effect compile、dedupe key、receipt serialization、parity fixture manifest/baseline tests；更新 semantic presentation snapshot 的 lineage。
