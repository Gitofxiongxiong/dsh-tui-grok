## 主要风险

- 缓存的行高与 renderer 加入的 vpad 不一致，破坏 Fenwick layout/anchor。
- 动态 accent 若在缓存建立时固化，实时 thinking/execute 将不再动画。
- thinking 折叠/截断与 mixed assistant block 的 `block_index` 可能偏移，影响命中测试和选择。
- user band 的 vpad/背景若双重应用，会出现额外空行或背景断裂。

## 回滚策略

- 新 vendor 模块与 `scrollback.rs` 是独立接缝，可逐文件移除。
- `transcript.rs` 按 S2/S3/S4 分层接入；某层失败时只回退该层调用点，不修改 DSH scrollback 状态机。
- 本任务不执行 destructive git 操作，不主动提交。

## 执行结果

### S2：appearance 与 accent 语义

- 在 `appearance.rs` 增加 renderer-neutral 的 animation、thinking、prompt、tool、execute 配置，并由 `GrokAppearanceSnapshot::scrollback(theme)` 每帧生成 value snapshot。
- thinking 使用 `gray_dim`；execute running/success/error 分别使用 `accent_running`、`accent_success`、`accent_error`，不再由 transcript 写死 primary 波色。
- runtime 在每帧同步 scrollback appearance，没有引入 Grok config store、file watcher 或运行时依赖。

### S3：renderer 生产接入

- 迁入并适配 `scrollback/types.rs`、`wrappers/block_renderer.rs`、`wrappers/entry_renderer.rs`。
- `BlockRenderer` 统一物化 wrap、vpad 和背景；`EntryRenderer` 统一绘制 `┃` / `❙`、两列左填充、`◆` bullet、动态 wave、selection freeze 与 finish flash。
- 新增 `scrollback_adapter/project_entry.rs`，DSH DTO 只在此投影；`ProjectedLine` 与 block materialization 也归入适配层，避免继续扩张 `transcript.rs`。
- 删除 `decorate_line`、`apply_dynamic_accent`、本地 `DisplayMode`、`render_row_at_width`、`collapsed_block_line` 等旧生产实现。

### S4：thinking/user/agent blocks

- `user.rs` 统一拥有 prompt prefix、三行折叠、ellipsis、vpad、band background。
- `thinking.rs` 统一拥有 `Thinking…`、`Thought for`、Collapsed/Truncated/Expanded、header gap、last-N 截断、gray-dim rail/bullet。
- `agent.rs` 消费固定 markdown styled lines，明确无本地 accent/vpad。
- timestamp 跳过 user 的顶部 vpad，挂到首个可选择内容行；thinking finish flash 结束后清除缓存 rail，避免残留动态 chrome。
- Execute header 统一为 `◆`，running/completed/failed 使用对应语义 accent。
