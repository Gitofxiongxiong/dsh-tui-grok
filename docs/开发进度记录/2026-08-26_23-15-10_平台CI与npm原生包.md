## 目标与背景

平台兼容 step 1–4 已合入（spawn、开发脚本 argv、剪贴板、Node 协议 mock）。
本批次完成 **step 5**：GitHub Actions 在 ubuntu / macOS / Windows 跑 `cargo test`，
并按 v2 方案落地 `@dsh-pager-grok/native-*` 平台包骨架、本机 strip 后 `npm pack`
审计。不实现 CLI / runtime Bundle（v2 PR 1–2），不自动 `npm publish` 到 latest
（发布链要 OIDC，且 CLI 必须最后发）。

## 设计契约和复用依据

- 对应计划：`docs/PRODUCT_PLUGIN_LAUNCHER.md` v2「npm 平台原生包」、发布顺序、
  平台矩阵（linux gnu x64/arm64、darwin x64/arm64、win32 x64；musl 拒绝）。
- Grok source path、commit、SOURCE_REV：上游无 GitHub Actions；不复制 Grok
  pager-bin / wrap。复用等级 **D**（CI 与 native pack 为 DSH 产品分发）。
- npm `os` / `cpu` / `libc` 为官方 package metadata，不是自造平台探测。

## 风险、回滚和依赖

- 风险：`ubuntu-24.04-arm` 在免费 runner 上可能不可用 → release 矩阵含该行，
  失败可从该次 release 拿掉，不阻塞 CI 三 OS 测试。
- 风险：release 二进制体积未知 → 以本机 `npm pack --json` 实测为准，不设 40MB 主观门。
- 回滚：删除 `.github/` 与 `packages/native/`、pack 脚本。
- 依赖：本机 `cargo`/`strip`/`node`；CI 用 rust-toolchain 1.98.0 + Node 22。
