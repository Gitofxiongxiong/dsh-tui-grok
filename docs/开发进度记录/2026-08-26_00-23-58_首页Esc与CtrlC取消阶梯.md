# 首页 Esc 与 Ctrl+C 取消阶梯

> 记录时间：2026-08-26 00:23:58 +0800
> 操作者/agent：Grok
> 状态：partial

## 目标与背景

首页（无 overlay）上 Esc 在空 prompt 时直接 `Quit`，和 Grok 不一致：Grok
`try_handle_esc_policy` 在非 vim 首页从不退出，运行中的 turn 用 Esc 取消。
Ctrl+C 也没有 Grok 的 CancelTurn 阶梯。Turn status 的 Stop 点击路径已经能
发 `CancelSession`，但键盘走不到同一条 effect。

## 设计契约和复用依据

- 对应长期计划章节：2.2 交互契约、Esc ladder、Grok 快捷键所有权。
- Grok source path：
  - `AgentView::try_handle_esc_policy`
  - `ActionId::CancelTurn`（`vendor/grok/xai-grok-pager/src/actions`）
  - `build_hints(..., esc_would_cancel_turn)` 把 CancelTurn hint 改成 Esc
- Grok mirror commit：`19d42e35c07a9c9244f03f6df0c4c353f970d4f9`
- SOURCE_REV：`7d67deacbeb1c1093fdb4f9bcbfab2630e18a6aa`
- 复用等级：B（首页按键阶梯与 hint）；C（`UiIntent::CancelSession` 接线）
- DSH-neutral seam：view 仍只返回 `ShellAction::CancelTurn`；runtime 调已有
  `CancelSession` effect。不改 protocol。

Esc / Ctrl+C 规则（overlay 仍先偷键）：

- Esc：running 或 cancel_pending → `CancelTurn`（即使有草稿）；idle 草稿 →
  清 prompt；idle 空 → swallow。Esc 永不 `Quit`。
- Ctrl+C：有草稿 → 清 prompt（turn 继续跑）；空且 running 且未 pending →
  `CancelTurn`；idle 空或已在取消 → `Quit`。

## 风险、回滚和依赖

- 风险：习惯用 Esc 退出的用户现在要 Ctrl+C（空闲两次或一次空闲空 prompt）。
- 风险：overlay 打开时 Esc 仍归 overlay；homepage 策略不得抢 Agent Detail。
- 回滚：还原本记录列出的文件。
