# Windows Modal 测试隔离

> 记录时间：2026-08-30 19:06:39 +0800
> 操作者/agent：Codex
> 状态：completed

## 目标与背景

release workflow PR #5 在 Windows 全绿后 rebase merge；同一源码的 main CI run
`33307702885` 中，Windows `cargo test` 的 648 个 UI lib 测试仅
`views::session_picker::tests::modal_uses_grok_resume_title_and_geometry` 失败：预期居中
`Rect(17,4,65,22)`，实际偶发得到 embedded 全屏 `Rect(0,0,100,30)`。

只读审计确认 `modal_window::embedded_fills_area_without_centering` 会在测试进程中切换
process-global `EMBEDDED: AtomicBool`。该测试虽标记 `serial_test::serial`，session picker
几何测试未加入同一 serial group，因此两个测试并行时会观察到临时 `true`。PR run 的
同一 Windows job 全绿、main run 单点失败，也与该竞态吻合。

## 设计契约和复用依据

- 只给依赖 process-global modal mode 的 session picker 几何测试增加
  `#[serial_test::serial]`，与唯一写入者共享 serial lock；不改变 production 逻辑、
  modal 几何、Rust wire 或 TUI 输出。
- Grok source：`crates/codegen/xai-grok-pager/src/views/session_picker.rs`，mirror commit
  `19d42e35c07a9c9244f03f6df0c4c353f970d4f9`，SOURCE_REV
  `7d67deacbeb1c1093fdb4f9bcbfab2630e18a6aa`。
- 复用等级：B native-only adaptation 的 test isolation 增量；同步更新 vendored hash 与
  local-change 说明。

## 计划修改范围

- `crates/dsh-pager-grok-ui/vendor/grok/xai-grok-pager/src/views/session_picker.rs`
  - 给失败几何测试添加 serial 属性。

  - 更新 vendored SHA-256，并登记 process-global modal test isolation。

npm/Tag/Release 操作。

## 风险、回滚和依赖

- 风险仅为单个测试与另一 serial 测试不再并行，测试耗时变化可忽略。
- 回滚为 revert 本批 commit；若 Windows 仍以同一断言失败，则停止该方向并重新审计
  其他 process-global writer，不通过无依据重复 rerun 声称解决。

## 实际修改

  `embedded_fills_area_without_centering` 共用 serial lock。
- 未修改 `EMBEDDED` production 实现、render 路径或任何几何期望。
