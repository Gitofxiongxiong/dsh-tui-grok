## 目标与背景

完成本地平台兼容 **step 3**：让 copy/paste 的 **clipboard 投递** 在 Ubuntu、macOS、native Windows 和 WSL 上按 Grok 的 native+OSC52 路由工作。

当前 `crates/dsh-pager-grok-ui/src/clipboard.rs` 只按 `WAYLAND_DISPLAY`/`DISPLAY`/macOS 选 `wl-copy`/`xclip`/`pbcopy`，**没有 Windows native**；无 display 的 WSL 也是 `None`。`runtime.rs` `flush_copy` 是 **XOR**：`capabilities.osc52` 为真时只发 OSC 52，不再写桌面剪贴板。Grok 是 native **and** OSC 52 多路投递。

Step 1（`6f013d0`）和 step 2（`e7f1ac6`）已落地。本批不碰 spawn、ROLE、stderr pipe 或 `start-new-chat.sh`。

  - 22 个 clipboard 单测：纯选择表、WAYLAND/X11 env isolation（`serial_test`）、Windows=arboard 非 None、multi-fire 三态、unix deadline kill。不碰真实 pasteboard。
