## 风险、回滚和依赖

- 风险：本机 `bin.js` 仅 `-r` 不 `-x` 时旧脚本失败、新脚本应成功；反之若 node
  不在 PATH 则默认路径失败（符合合同）。
- 风险：`DSH_TUI_SERVER` 仍 `split_whitespace()`，带空格路径继续不可用（文档写明）。
- `pty-smoke.py` 总会传 `--backend`（缺省 node+mock）；自定义 `DSH_TUI_SERVER`
  时 real-e2e 必须把覆盖串拆成 `--backend`/`--backend-arg`，否则会落到 mock。
- 不 `cargo build` pager，除非测试需要。
- 回滚：还原本记录列出的文件。
