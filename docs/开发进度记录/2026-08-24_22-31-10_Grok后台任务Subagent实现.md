## 目标与背景

在 `feat/grok-task-subagents` worktree 中，把已调研的 Grok Build 长时间后台任务与
subagent TUI 行为接入 `dsh-pager-grok`：顶部统一任务窗格、运行状态 cue、稳定 ID
选择、双击/Enter 详情展开、Esc 返回和 subagent interrupt effect。优先复用已有 Grok-derived
geometry、modal、turn-status、theme 和 DSH-neutral effect seam，不让 view 直接访问 RPC。

- 当前 DSH snapshot 的 subagent catalog 是同步 RPC 读取，需在 runtime 边界刷新，不能在 render/view 中调用。
- `session/jobs` 与 `subagent.list` 的字段可能不完整；缺失 activity/output 时必须保留明确 fallback，而不是伪造完成状态。

## 实际实现

- `ControlPlaneStore.jobs` 映射为带 `activity`、elapsed、output 摘要和 monitor 标记的
  `TaskRow`；inline top pane 只显示 running/pending/active 条目。
- `subagent.list` 在 runtime notification 边界刷新，view 只消费 `SubagentRow`；running
  activity 在顶部与统一列表中显示，continuable row 继续复用已有
  `UiIntent::InterruptSubagent`（`x`）。
- `AgentPaneController` 使用稳定 `AgentItemId`，鼠标第一次点击选择，第二次点击同一行
  在 450ms 内打开详情；列表 `Enter` 同样打开详情，详情 `Esc/q` 返回列表/主视图。
- `Ctrl+G` 与既有 `Ctrl+T` 均打开统一 Tasks/Subagents modal；顶部 watcher cue 在没有
  foreground turn、但仍有后台活动时显示计数与入口提示。
- mock backend 发出 `session/projection(capabilities.subagents)`、`session/jobs` 和
  running child catalog，保证浏览器场景可重复。
