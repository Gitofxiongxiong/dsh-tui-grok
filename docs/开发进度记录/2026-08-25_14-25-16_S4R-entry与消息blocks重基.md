- mixed assistant entry 内多个 blocks 必须保留 block index，fold/hit/copy 不能因新
  topology 重新编号。

- upstream user token/bash/cron/interjection 字段没有 DSH 真源时必须采用明确默认，
  不从文本启发式伪造。

## 实际修改

- `ProjectedScrollbackEntry` 现在携带可 round-trip 的 `ProjectedEntryId`、ordered
  `ProjectedRenderBlock`、原始 block index、display mode、running/finished 与三组时间戳；
  Image 无可绘制 payload 时成为显式 `Unsupported`，不伪造内容。
- assistant 的 Reasoning/Markdown/Plain/Tool/Diff 按原有 typed block 顺序投影；单块与
  mixed block 共用同一生产分派，修掉了普通 assistant 多块内容落回 generic renderer
  的旧路径。
- fold/hit/copy 继续使用原始 typed block index；entry identity 不再由数组位置推导。
- 新增稳定 ID、block 顺序、运行/完成态、fallback/unsupported 的 adapter 单测。
- thinking/user/agent 是以上游原文件为基线的 renderer-neutral B 适配，而非把
  738/1166/492 行连同 Grok runtime 逐行塞进 DSH。完成边界如下：

| Block | 保留并在 production 使用 | 由 DSH seam 替代 / D 类排除 |
|---|---|---|
| Thinking | Collapsed/Truncated/Expanded、running/finished header、last-N、elapsed、accent/bullet/background | DSH typed reasoning + Grok markdown renderer 替代 streaming cache；raw overlay/process timing 不进 vendor |
| User | prefix、visual wrap、三行 preview、ellipsis、background/accent-background、vpad | DSH user text/identity；Grok skill token/bash/cron/interjection 与直接 image runtime 无中性数据时不伪造 |
| Agent | ordered Markdown output、无本地 rail/vpad、stable source block index | DSH typed mixed blocks；Mermaid/media process/cache 不进入 renderer，缺 payload 的 Image 显式 Unsupported |

  该矩阵满足项目 B 级规则：保留同职责组件、display-mode 状态、不变量、测试与视觉
  规则；只切断 Grok session/agent/process 真源。它不是 A0 原文件声明。
