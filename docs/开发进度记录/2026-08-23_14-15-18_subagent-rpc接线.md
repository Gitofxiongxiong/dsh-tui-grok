时间：2026-08-23 14:15:18 +0800

## 目标

把 DeepSeek Harness 已存在的 `subagent.list` / `subagent.interrupt` authority 接入
Agent Tasks overlay，完成 Agent/Task/Subagent 的真实状态和动作闭包。

## 本批范围

- 打开 Agent Tasks overlay 时请求 `subagent.list`，把返回条目映射为稳定父子 ID、
  mode、activity/reason 状态。
- Agent Tasks 中对 continuable child 的 `x` 操作发出 interrupt admission；UI 只显示
  receipt/请求状态，最终 stopped 状态仍等待 host snapshot。
- 保留 one-shot child 不可 interrupt 的协议拒绝语义；不在 UI 中伪造 subagent 完成。
