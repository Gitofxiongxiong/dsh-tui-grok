# Grok 模型切换 ArgPicker

> 记录时间：2026-08-27 19:18:32 +0800
> 操作者/agent：Grok
> 状态：completed

## 目标与背景

`dsh-tui-grok` 尚未接通会话模型切换。Grok Build 的产品交互是扁平
type-to-find ArgPicker、`/model <name> [effort]` 链式 slash，以及
Ctrl+M（scrollback / 空 prompt 开 picker；prompt 焦点不抢 multiline）。
Host 真源是公开 ApiProxy `session.models` / `session.selectModel`，原位
换模型，不 fork。

## 设计契约和复用依据

- 对应长期计划章节：2.3 DSH 真源、2.4 中性 DTO seam、Grok 决定 UI。
- Grok source path、commit、SOURCE_REV：继续仓库内固定 Grok picker /
  modal_window；拷贝 `slash/commands/model.rs`、`effort_levels.rs` 的
  ArgPicker 行为，以及 `acp/model_state.rs` / `app/modals.rs` ArgPicker
  分支的结构。
- 复用等级：A1（vendor `/model` slash + effort 行构造）/ B（ArgPicker
  呈现）/ C（`session.models` / `session.selectModel` 是 Host 真源）。
- DSH-neutral seam：`UiIntent::{ListSessionModels,SelectSessionModel}`；
  不新增 `tui.setModel`；不 fork；不写本地 `model.json`。
- 失败测试、PTY/golden 和回滚：protocol camelCase、effect 编码、slash
  `/model` 不再 NotLocal、ArgPicker 链式 effort、caption 不再回退
  `"deepseek"`。回滚即还原本记录列出的文件。

## 风险、回滚和依赖

- 风险：DSH 身份是 `{provider, model}` 而 Grok 是单个 ModelId。缓解：
  catalog key 用 `provider/model`，提交时拆回 RPC 字段。
- 风险：Harness 不发 `model` 投影。缓解：UI 以 `session.models.current`
  和 select 响应为真源。
- 回滚：还原本记录文件。
- 依赖：已有公开 ApiProxy `session.models` / `session.selectModel`。

## 实际修改

- 协议：`SessionModelsValue` / `SessionSelectModelValue` 及 catalog DTO；
  `session_models` / `select_session_model` loader。
- Effect：`UiIntent::{ListSessionModels,SelectSessionModel}` 编码
  `session.models` / `session.selectModel`。
- 拷贝 Grok `ModelState` 到 `src/model_state.rs`（身份为 `provider/model`）。
- Vendor：`slash/commands/model.rs`、`effort_levels.rs`（A1 适配 DSH
  catalog / slash seam）。
- ArgPicker：`views/model_picker.rs` 拷贝 Grok `handle_arg_picker_input`
  与链式 effort、Esc 回退、`Pick model` / `Pick reasoning effort` 标题。
- Runtime：attach 拉 catalog；空 prompt Ctrl+M 开 picker；`/model <name>
  [effort]` 原位 select；caption 用 `ModelState.current_model_name()`；
  成功/失败文案对齐 Grok。
