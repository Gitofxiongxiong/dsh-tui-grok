# 升级 Harness 到 0.1.2-alpha.1

## 时间

- 开始：2026-08-29 20:46:39 +0800
- 结束：2026-08-29 22:37:29 +0800
- 状态：代码与非浏览器门禁完成；浏览器像素门禁受外部网络策略阻塞

## 目标与背景

按仓库根目录 `dsh-tui-grok-升级到harness-0.1.2-alpha.1分析.md` 完整实施
DeepSeek Harness `0.1.0-rc.8` → `0.1.2-alpha.1` 升级，并完成 TypeScript、
Rust、真实 Harness、PTY 以及 ttyd/xterm.js 浏览器视觉验证。

新版 Harness 已删除 `@deepseek-ai/dsh-host-apiproxy`，并把会话、设置、工作区、
审批/问答和流式状态迁移到 Typert Remote 控制器及 Cordis 事件。项目必须在
`dsh-tui-server` 内重建适配边界，同时冻结现有 TUI JSON-RPC v1，使 Grok UI
无需跟随 Harness 内部类型重写。

## 必须保持的合同

- TUI 协议版本仍为 1；现有 55 个 unary 方法名与 `events.mux` / `events.host`
  兼容帧词汇保持不变。
- `dsh-tui-protocol` 自己拥有兼容期 `ApiResult`、`MuxFrame`、`HostFrame` 与方法目录，
  不再引用已删除的 ApiProxy 包。
- `session.prompt` 与 `subagent.prompt` 的 `requestId` 使用调用侧已有操作 identity，
  不在桥层临时随机生成。
- attach 启动每会话 follower；首个 history 使用 opening snapshot，旧页固定
  opening cursor；detach、重复 hello 与 generation 切换必须 abort 旧 follower。
- chunk row 必须无损展开成旧 `assistant/chunk` 事件；工具展示重算失败只能软降级。
- approval / user-questions waterfall 只领取当前已 attach 的 runtime-root session；
  pending id 稳定、重连可重放、应答至多一次。
- Dashboard cold peek 使用 `sessionController.inspect`，不因读取尾部激活 Agent。
- profile 删除新版 base 已提供的 storage/projection rows，退役 cold recovery，新增
  session/settings/workspace controller，并显式禁用 feedback telemetry。
- 默认启动链只能选中可验证为 `0.1.2-alpha.1` 的 Harness，不得静默回退 rc.8。
- Grok vendor 源码和非升级相关 UI 行为不改。

## 风险

- history opening snapshot 与 live barrier 接错会造成丢帧、重帧或旧页游标漂移。
- interaction waterfall 若 scope 判断或 abort 清理错误，会抢答别的 surface 或留下悬挂请求。
- 新旧 projection、model、preset 形状不同，错误展平会让 Dashboard 首屏与选择器失真。
- 新 profile 与旧安装不可混用；必须重建本项目开发 profile。
- 沙箱 Chromium 当前受 AF_UNIX 权限限制；完整浏览器视觉门禁依赖已准备的 HTTPS/WSS
  中继路径。如果外部 Nginx 尚未部署，只能把它记录为外部阻塞，不能冒充已验证。

## 结果

### 实施结果

- `dsh-tui-protocol` 已接管兼容期 `ApiResult`、55 个 unary 方法目录、mux/host
  帧类型，不再依赖已删除的 `@deepseek-ai/dsh-host-apiproxy`。
- 新增 `TuiHarnessBridge`，把 0.1.2-alpha.1 的 session/settings/workspace、history
  opening snapshot/page/chunk、live follower、approval/question waterfall、tool view 与
  cold inspect 映射回冻结的 TUI JSON-RPC v1；gateway/dispatch/serve 只依赖该桥。
- embedded/runtime profile 删除重复 storage/projection/ApiProxy/recovery，加入新版
  controller 与 subagent model-selection settings，禁用 feedback telemetry；cold
  recovery 包及其 workspace/runtime/pack 引用已退役。
- Rust prompt/subagent prompt 全链使用调用侧 `requestId`；初始 prompt 使用稳定
  `dispatch-initial:{session}` identity，mock 会拒绝缺失 identity 的请求。
- 启动解析器只接受精确 `0.1.2-alpha.1`，优先当前工作区旁的
  `deepseek-harness-latest`，显式拒绝 `deepseek-harness-first` 的 rc.8，且不再静默
  回退旧 checkout。

### 浏览器视觉门禁：外部阻塞

- 本地 `ttyd 1.7.7` 能以 mock backend、`TERM=xterm-256color`、DejaVu Sans Mono
  16px、固定 `#0a0a0a/#e1e1e1` theme 启动；未暴露 shell、真实凭据或真实会话。
- 普通 Chrome 151 因沙箱禁止 AF_UNIX profile singleton 而退出；同版本
  `chrome-headless-shell` 可成功启动，说明渲染二进制本身可用，但本轮必须使用
  Browser skill 的云浏览器控制面，不能改用旁路 Playwright 冒充该门禁。
- 云浏览器可正常打开 `https://aidreamschool.cn`，但该 vhost 尚无 ttyd/WSS relay；
  `http://terminal.local:7681` 与私网 IP 被 URL 策略拒绝，`file:` 入口也被策略明确
  禁止且不得绕过。
- account-less Cloudflare HTTPS tunnel 能创建一次性 hostname，但沙箱强制代理在
  `h2.cftunnel.com` Edge 注册阶段连续固定约 20 秒后关闭连接；用户服务器 SSH
  从沙箱返回 `Network is unreachable`，当前权限策略也不允许申请外部网络提升。
- 因浏览器从未加载到 `.xterm`，没有产生 DSH/Grok 截图或像素 diff。本记录不得
  宣称视觉 parity；完成条件是外部服务器启用已准备的 HTTPS/WSS relay 后，按
  1200×800、DPR 1、真实 keyboard/mouse/paste/resize 重跑并补充证据。
