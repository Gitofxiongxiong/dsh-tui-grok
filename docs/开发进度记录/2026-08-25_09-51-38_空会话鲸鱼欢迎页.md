## 目标与背景

当前 Grok 主视图在空会话时只显示 `No transcript events yet`，顶部和 prompt
边框还可能显示包含 Session ID 的回退标题。按用户审核通过的方案，将空会话区域
改为 DeepSeek 鲸鱼欢迎页：宽终端播放一次 40×25 像素鲸鱼动画，右侧显示品牌、
模型、模式和 Shift+Tab 提示；窄终端使用文字降级。页面不显示 Session ID，
左上角改为当前会话工作目录，prompt 边框不显示标题。

## 风险、回滚和依赖

- 风险：真彩色和半块 glyph 依赖终端能力；现有 xterm.js/ratatui 链路支持 RGB，
  透明像素显式继承 `theme.bg_base`，避免颜色泄漏。
- 风险：短视口容纳不了 13 行鲸鱼；通过尺寸门槛切换为文字态，绝不裁切输入框。
- 风险：快照 fixture 增加 cwd 后可能触发序列化差异；字段提供默认值并同步相关
  semantic fixture。
- 回滚：删除 welcome 模块/导出，恢复 runtime 的空态 Paragraph、session title
  状态栏和 prompt title，并移除 `cwd` DTO 字段。
- 依赖：现有 ratatui、Theme、SessionState projection；不新增 crate。
