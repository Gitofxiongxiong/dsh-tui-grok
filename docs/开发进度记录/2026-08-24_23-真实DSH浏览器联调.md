## 验证结果

### Handshake/PTY

```text
DSH_TUI_PROFILE=dsh-pager-grok-real-e2e-20260824 REAL_E2E_TIMEOUT=60 scripts/real-e2e.sh
real DeepSeek Harness E2E checks passed (hello/list/dashboard/load/PTY)
```

真实 server 返回：`deepseek-harness-tui/0.1.0-rc.8`。

### Browser

真实 prompt 经 LLM 规划后请求 sandbox escalation；浏览器选择 `1 (Yes, proceed)`，
随后真实 host 返回 job id `bash-1`。实际运行中截图显示：

```text
▾ Tasks 1
▸ ⠴ sleep 20 · running
The command has started as a background job (job id bash-1)
```

截图 `10-real-dsh-task-running.png` 保存这一路径；等待真实 `sleep 20` 结束后，截图
`11-real-dsh-task-settled.png` 保存任务从顶部 live pane 移除、Host context 报告
`status: completed, exit code: 0`、并进入 `job_output` 读取阶段的状态。浏览器断言真实
文本包含 `Tasks 1`、`sleep 20`、`running` 和 `bash-1`，结束截图包含 `completed`。
