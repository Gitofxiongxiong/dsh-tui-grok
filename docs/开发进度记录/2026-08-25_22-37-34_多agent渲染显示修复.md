# 多 agent 渲染显示修复

> 记录时间：2026-08-25 22:37:34 +0800
> 操作者/agent：Grok
> 状态：completed

## 目标与背景

真实 TUI 里多 agent 有三处可见错误：

1. 父会话 transcript 调用 subagent 时只画 `subagent`，没有 Grok 那种总结性描述。
2. 顶部 pane 双击打开的 Agent Detail 预览把每次 thinking upsert 当成独立行，正文几乎不可读；modal 右上角 `[x]` 点击无效果，因为 `AgentTasksMouse` 被丢掉。
3. prompt 上方 `N subagents still running` 左侧脉冲点跟 `self.frame` 走，通知一密就疯狂闪。

对照 `/home/leo/code/grok-build`：Grok 用 `SubagentBlock` 画 `"description"`，子会话走完整 AgentView/scrollback，watcher 用 `MONITOR_PULSE_DIVISOR=8` 的 `○ ◎ ◉ ◎`。不能把 Grok ACP AgentView/runtime 整段搬进 DSH（D 级排除），但 TUI 表面可以按同职责复用。
