## 目标与背景

为仓库增加一个可从任意工作目录执行的开发启动脚本。默认连接本机真实 DeepSeek
Harness 的 `grok-tui` profile，构建最新 Rust pager，并显式传入 `--new` 创建隔离的新
对话，避免每次手工拼接 backend 命令。

## 设计契约

- 脚本只负责进程入口和参数装配，不改变 protocol、session authority 或 Grok UI。
- 默认使用 `/home/leo/aidreamschool/deepseek-harness`，兼容仓库文档中的
  `/home/leo/code/deepseek-harness`；允许通过 `DSH_HARNESS_ROOT`、`DSH_TUI_PROFILE`、
  `DSH_TUI_SERVER` 覆盖。
- 优先使用 PATH 中的 Cargo，并为当前机器提供 `/home/leo/.cargo/bin/cargo` fallback；
  允许通过 `DSH_TUI_CARGO` 覆盖。
- 正常执行始终使用 `--new`；提供无会话副作用的 `--check` 握手模式，便于确认 backend
  和 profile 可用。
- 使用 `exec` 交接 pager，确保 Ctrl+C、终端恢复和退出码直接由 pager 管理。
- Grok source/reuse：不涉及 Grok 源码或 UI 组件；复用等级不适用。
- DSH contract delta：无 DTO、Intent、Effect、wire method、identity 或 generation 变更。

## 风险、回滚和预期验证

- 风险：Harness 路径、profile、Cargo 不存在时启动失败；脚本应在构建或进入 raw mode 前
  输出明确错误。
- 行为边界：正常启动会创建一个真实空 session；测试只运行 `--check`，不发送 prompt、
  不创建会话。
- 回滚：删除启动脚本，并恢复 README 的启动说明。
- 验证：`bash -n`、脚本 `--check` 的真实只读 `tui.hello`、帮助/非法参数、Cargo fmt、
  `git diff --check`。

## 实际修改

- 新增可执行脚本 `scripts/start-new-chat.sh`。脚本从自身位置解析仓库根目录，构建
  `dsh-pager-bin --locked`，设置 backend 命令，并以 `--new` 通过 `exec` 启动 pager。
- 默认选择本机 `/home/leo/aidreamschool/deepseek-harness` 和 `grok-tui`，保留旧
  `/home/leo/code/deepseek-harness` fallback；Cargo 同时支持 PATH、当前机器绝对路径和
  `DSH_TUI_CARGO`。
- 增加 `--check`、`--help` 和非法参数退出路径。`--check` 只运行 `tui.hello`，不加载
  或创建 session。
- README 增加新对话启动、只读检查和环境变量覆盖说明。
