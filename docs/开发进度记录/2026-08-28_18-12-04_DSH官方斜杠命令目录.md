## 目标与背景

当前 Grok-derived 斜杠菜单只有五个 TUI 本地命令，并把所谓 Host suggestions
接到一个永远为 `active: false` 的 projection，导致 DSH 已注册的 `/plan`、
`/permission`、`/goal`、`/compact` 等命令不出现在菜单。完整手输虽然会经
`session.prompt` 透传，但缺少发现、官方描述、参数 hint 和命令结果反馈。

本批次不新增硬编码 DSH 命令表。TUI server 直接读取 DSH 官方
`ctx.commands.list(agent)`，沿用其 Remote 方法名/参数形态 `commands/list` +
`agentId`，经现有 stdio carrier 送给 Rust host；Grok `SlashController` 继续拥有
菜单、模糊匹配、选择、补全和 Enter 状态机。TUI 本地命令与官方 session 命令在
adapter seam 合并，重名时保留 TUI 本地命令所有权。

## 风险、回滚和依赖

- 风险：目录请求可能晚于首帧；UI 先显示本地命令，目录结果到达后同一 Grok
  controller 自然刷新，不阻塞输入。
- 风险：agent preset 目录不同；只使用按 `agentId` 解析后的官方列表，并在 preset
  选择或 session attach/new 后失效重拉。
- 风险：DSH registry 暂时不可用；保留本地命令并显示 typed diagnostic，不把已知
  DSH 命令猜进菜单。
- 依赖：Embedded base 已组合 `commands`，tui-server 增加显式 Cordis injection 和
  peer dependency，避免隐式跨服务访问。
- 回滚：回滚本记录绑定的单一 commit；`session.prompt` 执行协议没有迁移数据。
