## 目标与背景

在仓库主 README 中展示 `dsh-tui-grok` 的 GitHub Star 数量增长折线图。
GitHub 已收紧 stargazer 历史接口，因此不依赖无凭据的第三方实时图片，
改由本仓库 GitHub Actions 使用仓库自带的 `GITHUB_TOKEN` 生成明暗两版
SVG，并让 README 引用仓库内的稳定路径。

## 设计契约和复用依据

- 对应长期计划章节：§2.8 变更前进度记录契约、§2.9 Git 提交契约。
- Grok source path、commit、SOURCE_REV：不适用；本次不改动 Grok-derived TUI 代码。
- 复用等级：C；这是仓库文档与 GitHub 统计自动化，不存在 Grok 同职责 UI 复用面。
- 图表只保存累计 Star 数与日期，不保存或展示 stargazer 身份。
- 自动更新也遵守一记录一 commit：只在 SVG 内容变化时生成新的时间戳记录，
  并在 bot commit 中写入 `Progress-Record` trailer。

## 风险、回滚和依赖

- 风险：GitHub GraphQL 接口或 `GITHUB_TOKEN` 权限变化会使自动更新失败；
  主分支保护规则可能拒绝 bot push。
- 缓解：生成脚本对 API 错误明确失败，并在提交前运行 SVG/XML 与 diff 检查；
  当前 `main` 未启用 branch protection。
- 依赖：Node.js 22 内建 `fetch`、GitHub GraphQL API、GitHub Actions 内建 token。
- 回滚：回退本批 commit，即可同时移除 README 图表、生成脚本、工作流与 SVG。
