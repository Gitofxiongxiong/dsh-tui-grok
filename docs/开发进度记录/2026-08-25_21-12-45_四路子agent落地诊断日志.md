> 状态：completed

## 目标与背景

真实会话 `session-d0b39f12-2b2d-49d3-a745-0093f5a68c85` 在同一条 assistant
消息里派出 4 个子 agent 后约 60ms，TUI 退回 shell。hello/SessionLoaded 留在
主屏，panic 或 Node 堆栈会打在 alternate screen 上并随 restore 消失。本批次
加可落盘诊断，并用 4 路 host 帧 + 4 个 `subagent` tool 的离线渲染复现该路径。

## 设计契约和复用依据

- 对应长期计划：H6 subagent/jobs/tasks。
- 复用等级 C：诊断与测试只接已有 host adapter / scrollback host / runtime。
- 不改 vendor Grok 源码、协议 schema、Harness。
- panic hook 必须在 restore 之前把 payload 写入文件；`DSH_PAGER_DIAG` 打开
  后 interactive 路径的 catalog 刷新、通知错误和 Quit 也写入同一文件。
