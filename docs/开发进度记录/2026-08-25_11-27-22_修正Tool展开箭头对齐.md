## 目标与背景

Tool entry 双击展开后，首行使用 `⌄`（U+2304 DOWN ARROWHEAD）作为展开标记。
该字形在项目浏览器门禁使用的 DejaVu Sans Mono 16px 中落在字符格偏下，和同一行
的 `Run …` 文本基线视觉不齐。用户要求调整这一处展开态样式。

本批把 Tool 展开标记统一为项目其他 open-disclosure surface 使用的 `▾`，保持一格
宽度、折叠交互、稳定 entry/block identity、copy text 和 hit-map 不变。

## 实际修改

- 在本地 Grok glyph subset 增加 `glyphs::disclosure_open()`，返回 U+25BE
  `▾`；该字形与 Grok dashboard/open-section disclosure 相同，在 xterm.js 的
  DejaVu Sans Mono 字符格内垂直居中。
- `transcript.rs` 的 ExecuteToolCallBlock adapter 与 generic ToolCall fallback
  都通过同一个 glyph helper 绘制展开首行，不再硬编码 U+2304 `⌄`；对应
  `style_for_paint` 也以 helper 识别展开 header。
- 更新 transcript/runtime 回归断言：展开首行必须精确为 `▾ Run …`，marker
  span 与标题在同一个 `Line`，并显式拒绝旧 `⌄`；折叠态 `› Run …` 和双击
  fold state machine 保持不变。
- 更新 SOURCE_MANIFEST 中本地 `src/glyphs.rs` SHA-256 为
  `7d670d3a4a667b15c8cdcbdf8de5018e01c28403a03cccf3dd84bf651a02358f`。
