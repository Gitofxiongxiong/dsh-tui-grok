## 实际修改

- `host_adapter.rs`：新增 prompt history/suggestion DTO，并兼容 snake/camel capability keys。
- `input/mod.rs`：增加不丢失多行内容的 editor replacement seam。
- `app.rs`：将 Dashboard 加入统一 owner/overlay dispatch；Ctrl-P/N/X 不再误触发 picker。
- `views/dashboard.rs`、`views/mod.rs`：使用 Grok modal primitive 绘制 workspace/session
  hierarchy、stable selection、peek 结果和控制栏。
- `runtime.rs`：同步 `DashboardModel`/control-plane revision，接入 dashboard query/group/
  archive/collapse、peek→attach/back、prompt history/slash completion、external process
  capability feedback，并把 queue/interaction/prompt receipt 统一成 typed status 文案。
- `effects.rs`：RPC error 转换为 conflict/stale/timeout/unsupported/failed receipt，避免
  effect failure 绕过 receipt 边界。
- `docs/GROK_BUILD_TUI_DEEPSEEK_ADAPTATION_PLAN.md`：回写 M5-M7 completion-slice 状态和
  后续 reference/真实进程出口。
