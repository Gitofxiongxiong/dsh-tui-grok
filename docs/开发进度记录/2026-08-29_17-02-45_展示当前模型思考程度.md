## 目标与背景

当前 TUI 已在 prompt 底部信息行和空会话 welcome 页展示经过精确映射的
模型短名，但没有同时展示会话当前的 reasoning effort。本批按 Grok 原生
契约将两者合并为一个紧凑标签：`<model> (<effort>)`，例如
`dsv4 flash (high)`。

`off` 是明确选中的档位，必须显示为 `(off)`；只有 Host 当前选择中
`reasoningEffort` 为 `null`/缺失时才省略 effort。不从 catalog 推测或翻译
当前值。

## 设计契约和复用依据

- 对应长期计划：2.1 视觉契约、2.3 DSH 真源、M5 prompt/input、M10 宽窄屏 parity。
- Grok source：`/home/leo/aidreamschool/grok-build`，commit
  `19d42e35c07a9c9244f03f6df0c4c353f970d4f9`，SOURCE_REV
  `7d67deacbeb1c1093fdb4f9bcbfab2630e18a6aa`。
- Grok 对应源码：
  - `crates/codegen/xai-grok-pager/src/app/agent_view/render.rs`：prompt 使用
    `format!("{model_id} ({eff})")`；
  - `crates/codegen/xai-grok-pager/src/app/app_view.rs`：welcome 使用
    `format!("{model_name_base} ({eff})")`。
- 复用等级：B；保留 Grok 的复合标签语义，仅在现有 DSH 精确模型
  短名 seam 之后追加 Host-authoritative effort。
- DSH-neutral seam：继续使用 `ModelState.current_model_name()` 和
  `ModelState.reasoning_effort`；不新增协议、RPC、Intent 或 Effect。
- 宽度与命中契约：prompt/welcome 继续把整个复合标签当作当前
  model 项进行中间省略，paint-time model rect 覆盖实际画出的 effort 字符，
  双击继续打开现有模型 picker。

## 风险、回滚和依赖

- 风险：先拼 effort 再查模型映射会导致精确 alias 失效；由单一 helper
  固定“先 alias，后 effort”顺序。
- 风险：把 `off` 当作空值会隐藏重要状态；测试单独覆盖 `Some("off")`
  和 `None`。
- 风险：复合标签增长会影响窄屏；复用现有中间省略和原子 flag/
  preset 优先级，并覆盖 prompt/welcome 宽窄屏渲染。
- 回滚：回滚本记录对应的单一 commit，无数据迁移。
- 依赖：现有 `session.models` / `session.selectModel` 已提供当前
  `reasoningEffort`。
