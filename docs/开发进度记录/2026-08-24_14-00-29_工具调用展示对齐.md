## 风险、回滚和依赖

- 历史分页可能先收到 result 再收到 call，投影必须支持 orphan result 后续归并。
- 结构化 view 是软能力，解析失败不得吞掉原始工具内容。
- 分组从事件种类改为工具语义后会影响现有快照和 fixture；通过定向回放与语义测试
  固定兼容行为。
- 回滚方式：回退本记录对应的单一提交；协议和持久化格式不发生不可逆变化。

    DTO，覆盖 generic、terminal、diff、read、search、web 和文件位置/来源信息；
  - `DshPresentationAdapter` 按 `callId` 维护 pending tool，同一调用从 running
    原位更新到 completed/failed；result 先于 call 到达时先保留 orphan fallback，
    后续补页收到 call 后删除 fallback 并归并到 call 的稳定 entry/lineage；
  - transcript 使用 presenter title，而不是原始工具名/整段 JSON，绘制 Grok 风格
    terminal panel、diffstat/diff、行号 read、按文件 search、web source/status 和
    generic fallback；running/error/success 使用语义色，工具 rail 使用 `┃`，折叠组
    使用 `❙`；
  - Read/Search/Web 非破坏性工具形成 tense-aware semantic verb group，单成员即可
    折叠以避免后续跳变；Execute/Edit/Other 独立展示并打断 verb run；
  - 更新 fixture、mock presentation view、来源清单和长期计划状态，补充 call/result
    顺序、结构化 view、五类专用卡片和分组边界测试。
