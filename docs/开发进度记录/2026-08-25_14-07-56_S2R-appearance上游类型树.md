## 目标与背景

- 执行 `GROK_SCROLLBACK_CLOSURE_PLAN.md` 的 S2R：用固定 Grok Build 上游的
  scrollback runtime config 类型树替换当前本地重新声明的少数字段集合。

  提供 `appearance.scrollback.layout/blocks/display` 路径。

## 风险、回滚和依赖

- 上游配置含 `String`，类型不再 `Copy`；调用链必须借用 appearance，避免每 entry
  clone 整棵配置。
- 上游 prompt background 是语义 enum，不是 resolved Color；临时 user block 必须
  用当前 Theme 解析，确保本批不造成视觉变化。
- `ToolBullet::Circle` 依赖上游 glyph registry；本批补最小 `filled_dot` glyph，完整
  glyph registry 仍按原计划迁移。
- 回滚可按上述文件移除 S2R 接线并恢复原本地 structs；不使用 destructive Git。
