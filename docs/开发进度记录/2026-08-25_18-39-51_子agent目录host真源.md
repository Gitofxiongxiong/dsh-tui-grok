# 子 agent 目录 host 真源

> 记录时间：2026-08-25 18:39:51 +0800
> 操作者/agent：Grok
> 状态：completed

## 目标与背景

`dsh-pager-grok` 的后台任务已经通过父会话 `session/jobs` 推送进入顶部 Tasks pane。
子 agent 仍被 `capabilities.subagents` 和父会话 `tail_seq` 挡住，真实 DSH 目录
因此一直为空。本批次把 catalog 改成与 Web 客户端相同的 host 帧驱动 pull，并把
`kind=subagent` 的 Job 从 Tasks 组挪到 Subagents，为后续 Grok pane / child
fullscreen 对齐提供真源。

## 设计契约和复用依据

- 对应长期计划：H6 subagent/jobs/tasks、M2-5 subagents/jobs。
- Grok 对齐的是 TUI 表面，不是 `spawn_subagent` 运行时（D 级排除）。
- DSH 真源：`subagent.list`、`host/session-added origin=subagent`、
  `host/session-status`、`session/jobs kind=subagent`。
- 复用等级：C（host/control-plane/adapter）；不改 vendor Grok 源码。
- View 只消费 `AgentSnapshot`；`subagent.list` 只在 runtime 边界调用。

## 计划修改范围

- `crates/dsh-pager/src/control_plane.rs`：父级 catalog 缓存、stale 标记、
  host 帧占位/activity overlay、list 结果写入。
- `crates/dsh-pager/src/lib.rs`：导出 `SubagentCatalog`。
- `crates/dsh-pager-grok-ui/src/host_adapter.rs`：snapshot 投影 subagents，
  过滤 `kind=subagent` 的 TaskRow，合并 Job 与 catalog。
- `crates/dsh-pager-grok-ui/src/runtime.rs`：按 catalog stale 刷新，去掉
  capability/seq 门闩和 UI 私货 `agent_subagents`。
- `crates/dsh-pager-grok-ui/src/views/agent_panes.rs`：运行态只认
  `running|inactive`；补充投影相关测试。
- `crates/dsh-pager-bin/tests/mock-server.mjs`：真实 list schema，补 host
  child 帧和 inactive one-shot。
- 本进度记录。

不修改 protocol wire schema、vendor、deepseek-harness、gateway presentation
规则和 child fullscreen。

## 风险、回滚和依赖

- 真实 profile 若 `subagent.list` 失败，必须标 unsupported/错误，不能伪造行。
- one-shot Job 的 id 是 `subagent-N`，与 child session id 不同；无法匹配时
  两行并存，宁可重复不可丢失。
- 回滚：还原本记录列出的文件。

## 实际实现

- `ControlPlaneStore` 为每个父会话保留 `SubagentCatalog`。`host/session-added origin=subagent` 写入 creation-window 占位并标 stale；`host/session-status` overlay `running|inactive`；child removed 只把 activity 打成 inactive，不删行；parent removed 把 `parentAvailable` 打成 false。
- `subagent.list` 成功写入 catalog 后 overlay 子会话 live running 位。method-not-found 标 unsupported。不再用父会话 `capabilities.subagents` 或 `tail_seq` 做刷新门闩。
- `GrokHostSnapshot` 自己投影 `agent.subagents`。`kind=subagent` 的 Job 离开 Tasks 组；能按唯一 label 匹配时合并到 catalog 行，否则以 job id 作为 Subagents 行。
- mock `subagent.list` 改为真实 `running|inactive` schema，并补 child host 帧和一条 inactive one-shot。
