状态：已完成（插件门禁与仓库 Rust 编译门禁均通过）

## 目标

把 `/home/leo/code/deepseek-harness` 当前未提交的冷会话列表投影恢复改动，抽成
`dsh-pager-grok` 内可独立挂载的 DSH/Cordis 插件；不把 DeepSeek Harness 的宿主
源码、文档或测试整包复制进来，并保留两个仓库现有的其他未提交改动。

## 设计契约

- 插件只依赖公开的 `ctx.apiProxy.sessions.list` 和
  `ctx.sessionProjectionCache.coldSnapshot` seam；不 import 或 monkey-patch
  `deepseek-harness` 私有 `createApiProxy` 源码。
- 先保留宿主已有列表结果；只有缓存服务已挂载、行没有 `projections` 时才恢复。
- 恢复失败、空投影、取消和能力缺失都保持 fail-soft：行仍返回，投影列缺省。
- 恢复结果写回由 `sessionProjectionCache.coldSnapshot()` 自身负责；同一插件实例不做
  额外缓存，避免制造第二个权威状态。
- `sessionListMetadata` 恢复值用于修正冷行的 `blank` 与 `updatedAt`，不回写宿主真源。

## 风险与回滚

- `ctx.apiProxy.sessions.list` 是公开对象方法；插件只在自身 fiber 中替换并在 dispose
  时恢复原方法。`sessionProjectionCache` 是可选能力，未挂载时原样返回；其余 API
  形状由官方类型依赖在构建期约束。
- 插件依赖官方 `sessionProjectionCache` 的身份校验、折叠和写回；不会读取原始日志，
  不会把空/失败结果误报成标题。
- 回滚时移除 bundle patch 中的插件行及新增 workspace/package 文件；不触碰
  `deepseek-harness` 工作区，也不回滚本仓库其他未登记修改。

## 实际实现

- 新增 `@dsh-pager-grok/tui-session-projection-recovery` workspace 包：
  - 通过 `name` / `inject` / `Config` / `apply` 暴露标准 Cordis function plugin；
  - 只装饰公开的 `ctx.apiProxy.sessions.list`，不复制 Harness 私有实现；
  - 先跳过已有投影和 attached 行，对 detached 且缺列的行按 16 行批次调用
    `ctx.get('sessionProjectionCache')?.coldSnapshot()`；
  - 非空恢复值合并到 `projections`，`sessionListMetadata` 单调修正 `blank` 和
    `updatedAt`；缓存缺失、空值、异常 fail-soft，取消可传播，dispose 恢复原方法；
  - 包含无运行时不变式的解释性 invariant companion 和 HMR/dispose 测试。
- `dsh-tui-embedded` patch 在 projection cache 与 api-gateway 后挂载该插件，workspace、
  profile 自举脚本、lockfile、bundle 测试和双语 README/外置插件说明均已同步。
- `deepseek-harness` 中来源改动的 9 个文件已逐项反向撤销；来源仓库 `git status --short`
  为空。没有使用 broad reset，也没有修改 Harness 其他文件。
