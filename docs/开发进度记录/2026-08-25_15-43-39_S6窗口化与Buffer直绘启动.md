## 合同

- `revision` 只在 entry topology/content/visibility 或 renderer-relevant height 输入改变时
  前进；单纯读取/layout/paint 不得改变它。
- borrowed seam 的生命周期不能逃逸 host；UI 不缓存 host 引用，只缓存 neutral
  projection 或可见行。
- range/window API 必须对空历史、零高 entry、overscan、顶部 entry 被裁剪、尾部跟随和
  resize anchor 安全。
- renderer 直接 paint 后，hit-map/copy/selection/timestamp hover 必须仍从同一行几何生成。
- 不用“第一次 revision 全扫一遍”冒充“每帧窗口化”：性能测试分别统计 cold sync 和
  unchanged hot frame。

## 风险与回滚

- revision 漏增会造成陈旧 UI；所有 Scrollback mutation 入口都需测试。
- 高度索引依赖 width；range seam 不能绕过 Fenwick/anchor 合同。
- direct Buffer 改变 cell ownership，需特别覆盖 background、wide glyph gutter、窄屏
  timestamp、selection box 和 hover。
- 小步补丁；不执行 destructive git。S6 使用独立提交和本记录 trailer。

## 实施记录

- 2026-08-25 15:43:39 +0800：建立 S6 独立主记录，尚未修改 host/runtime 代码。
- 2026-08-25 15:54 +0800：host `Scrollback` 新增彼此独立的 monotonic
  `revision()` / `layout_revision()`；所有 canonical upsert/remove/rebuild/finalize 路径
  推进 content revision，而 width/renderer height 只推进 layout revision。
- 新增 `DshRenderEntryRef`、borrowed iterator/range、单 entry `to_owned()`、Fenwick
  `PaintWindow` 与 O(log n) `entry_layout()`；UI 不再调用全历史 `render_entries()` 或
  `layout.entries.to_vec()`。
- `ScrollbackPane` 现在在 content revision/width/appearance/fold/group/pending 改变时
  扫描 borrowed metadata；rich `DshRenderEntry` 和 semantic lines 仅在 viewport ± 一个
  viewport overscan 内物化，移出窗口即回收。wave tick/hover/selected target 不置脏。
- production `GrokHostSnapshot::for_render` 改走 `presentation_controls()`；settled
  transcript DTO 为 0，只为 running/pending tool 保留最多 4 条 support rows；完整
  `from_session` 仍供导出与测试。历史 media 用 borrowed
  metadata 按 content revision 缓存，避免 draw 前偷偷恢复整段 clone。
- runtime 删除 transcript `Paragraph<Text<Vec<Line>>>` 和手写 timestamp overlay；边框后
  逐可见行调用 `EntryRenderer::paint_buffer_line`，timestamp hover rect/label 也由同一
  painter 返回并写入 hit map。resize/reset 同步清理 mouse position。
- 从固定 Grok mirror 复制/适配 `scrollback/render.rs` 的
  `content_y0/entry-base/skip_rows/total_height` 纯窗口合同，以及 `sticky.rs` 的渐进收缩、
  next-prompt push/clip 与 bottom-line continuity 纯坐标合同。vendor 文件不引用 DSH
  runtime；sticky 还没有接入 production composition。
- 增加 50,000 entries instrumentation：cold revision scan 为 50,000 个 borrowed metadata、
  0 个 rich materialization；首个 24-row viewport 物化少于 100 entries；随后 8 个
  unchanged animation frame 为 0 revision scan、0 新 materialization，painted lines 不
  超过 `24 * 8`。另有 production snapshot bounded-tail、host revision/read/range 测试。
