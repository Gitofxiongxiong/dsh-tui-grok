# 主分支修复绝对路径误判

> 记录时间：2026-08-30 10:08:24 +0800
> 操作者/agent：Codex
> 状态：completed

## 目标与背景

- 用户确认 Harness `0.1.2-alpha.1` 升级分支的修复后，要求主分支也修复
  prompt 以 Unix 绝对路径开头时被误当成 unknown slash command 的问题。
- 主分支 `00d93ba` 与升级分支在 `dispatch_prompt_submission` 和
  `parse_invocation` 的相关逻辑一致，因此存在同一 bug。
- 本批仅迁移窄修复和回归测试，不带入 alpha 分支的 Harness、README、
  clippy 或其他独立变更。

## 设计契约和复用依据

- Grok 对应源码：vendored `slash::parse_invocation` / `slash::analyze_input`。
- 复用等级：B（slash 输入分类的最窄 DSH 适配）。
- DSH-neutral seam：普通 prompt 仍走 `SubmitPrompt`；已登记 local/Host slash
  command 仍走现有 local action 或 `ExecuteCommand`。
- local 与 Host registry 共享的 command-name grammar 是 ASCII 字母数字、`-`、
  `_`；包含额外 `/` 的 token 不可能是 command，可安全回退为 prompt。
- 保留 `/plna` 等语法合法拼错的 unknown-command 与 catalog refresh 行为。

## 计划修改范围

- `crates/dsh-pager-grok-ui/src/slash.rs`
  - 新增 command-shape helper 和绝对路径/合法/拼错命令回归测试。
- `crates/dsh-pager-grok-ui/src/runtime.rs`
  - 在 unknown-command 分支前把不符合 command grammar 的 leading-slash 文本送回
    普通 prompt 路径。
- `crates/dsh-pager-grok-ui/SOURCE_MANIFEST.md`

- `docs/开发进度记录/2026-08-30_10-08-24_主分支修复绝对路径误判.md`
  - 记录实施、测试、视觉证据和提交审计。
- 不在范围内：README、Harness bridge/profile、vendor Grok 文件、fixture、
  lockfile 和其他主分支文件。

## 风险、回滚和预期验证

- 风险：过宽回退会让 `/plna` 进入模型；用共享 command grammar 限定边界。
- 已知歧义：`/tmp` 本身符合 command grammar，仍会作为未知命令；本批
  修复明确包含第二个 `/` 的绝对路径。
- 回滚：revert 本记录对应的单个提交。
- 验证：定向 UI 测试、source manifest、`scripts/e2e.sh`、三组 PTY，
  以及 ttyd+xterm.js+Playwright 的 DSH/Grok paste/Enter/resize 对比。

## 实际修改

- `slash.rs` 增加 `is_command_candidate`，复用 local/Host registry 共享的
  `valid_command_name`；`/home/leo/...`、`/usr/bin/env`、`/路径/项目`
  不再是 command candidate，`/plan` 和 `/plna` 仍是。
- `runtime.rs` 在 local/Host/unknown-command dispatch 前应用该分类；非 command
  shape 的 leading-slash 文本走原有 `submit_prompt`，不改 effect/receipt 语义。
- 回归测试覆盖 Unix/Unicode 绝对路径、合法 command、拼错 command、
  单独 `/` 和普通 prompt。
- `SOURCE_MANIFEST.md` 只更新 manifest date、`src/slash.rs` vendored hash
  `b1ddffe1db0441d706c7a709f77534c2cf564d8c1a7b850115240ddf90c9ddcb`
  和该 B/A1 适配说明；upstream path/hash/revision/license 不变。
- 未迁入 alpha 分支中与本 bug 无关的 clippy、README 或 Harness 变更。
