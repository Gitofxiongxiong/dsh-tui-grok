# 详情层 Esc / q / [x] 无法关闭

> 记录时间：2026-08-25 23:15:02 +0800
> 操作者/agent：Grok
> 状态：completed

## 目标与背景

上一批已经把子会话 history 画进 Agent Detail，并接线了 `AgentTasksMouse`。
真实会话里 `[x]`、Esc、`q` 仍然全部无效。

根因不是命中区域单独失败：主循环在每次绘制前同步调用
`peek_subagent_history`（`transport.call` 最长阻塞 30s）。子 agent 运行时
这条 RPC 把输入读循环堵住，键盘和鼠标都进不了 `handle_agent_tasks_*`。

## 设计契约和复用依据

- Grok：`q`/`Esc` 只返回父会话，不 cancel child；modal `[✗]` 是 CloseRequested。
- 复用：已有 `handle_modal_mouse` / `close_overlay`。
- 等级 B/C：不引入 Grok child AgentView，不把 `subagent.history` 放到 UI 热路径。
- 打开详情时仍同步 peek 一次；live 刷新留给以后的非阻塞 poll。

预期：

- 主循环在 Agent Detail 打开时不再同步 peek。
- Esc / q / Q / Ctrl+G / `[x]` Down 或 Up / 点 modal 外 / 点 footer shortcut 关闭 overlay。
- 关闭不 interrupt 子 agent。

- 回滚：还原本记录文件。
