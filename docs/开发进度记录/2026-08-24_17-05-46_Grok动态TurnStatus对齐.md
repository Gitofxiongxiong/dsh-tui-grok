## 目标与背景

当前默认 TUI 在 transcript 与 prompt 之间只显示静态 `● Generating response`，
没有复用 Grok Build 左下角的动态 turn status。用户要求把 Grok 的执行中状态行
加入默认 `dsh-pager-grok-ui`：显示动态 spinner、当前活动、阶段/总耗时、token
数量、等待用户确认时的脉冲菱形，以及可点击的 `[stop]`。

本批保持 DeepSeek Harness 为运行状态与副作用真源；状态行只能消费 adapter
投影，取消操作必须经过 `UiIntent -> UiEffect -> receipt -> authoritative
SessionState` 收敛，不能由 view 直接调用 RPC。

## 风险、回滚和依赖

- 历史重放与实时事件混合时，活动 phase 不得因每个 delta 重置；用事件 seq/time 和活动类型转换确定阶段起点。
- Harness `SessionEvent.time` 为 epoch milliseconds；未来时间、缺失/非法值必须安全钳制，不得导致 duration 下溢。
- receipt 只是请求受理，不能立即隐藏状态行；以 `SessionState.running == false` 为最终收敛条件。
- 小终端要优先保留活动与 stop 可达性，并按 Grok 规则截断次要右侧信息。
- 回滚方式：revert 与本记录绑定的单一 commit；不涉及 wire/session 持久数据迁移。

## 实际修改

- 新增 Grok-derived `turn_status.rs` 纯渲染组件，保留其单行 spinner、活动文案、阶段/总耗时、token、等待输入脉冲菱形、窄屏截断和 `[stop]` 命中几何；文件内记录 B 级 adaptation 边界与上游来源。
- 在 glyph facade 中补齐 braille spinner 和 token arrow，并通过 `views/mod.rs` 导出组件；移除旧的静态 `● Generating response` 渲染入口。
- 新增 DSH-neutral `TurnActivitySnapshot`/`TurnStatusSnapshot`，从 Harness history、typed transcript、pending interaction 和 context usage 投影当前活动。连续 text/reasoning delta 不重置 phase 起点，tool presentation 可覆盖原始工具标题和描述。
- 新增 `CancelSession` intent/effect、同步 sink 和 async `session.cancel` 编译路径；operation identity/dedupe 仍绑定当前 session/generation。
- runtime 以约 30 FPS 驱动活动状态动画，接入 `[stop]` hover/click hit target，并在 cancel receipt accepted 后继续显示 `Cancelling…`，直到权威 host snapshot 报告 `running=false`。
- 标准与 40x12 小终端都保留活动状态行；小终端优先压缩 prompt 间距并按 Grok 规则截断状态行。
- 补充 renderer、adapter、effect、runtime 与 semantic parity 测试；更新 `SOURCE_MANIFEST.md` 和长期适配计划的 M7.5 完成边界。
- 未修改 `crates/dsh-pager/src/*` 或 wire protocol；现有 public DTO 已足够表达本批权威状态。
