# 滚动条与上下文状态对齐

> 操作者/agent：Codex
> 状态：completed

## 目标与背景

当前主 AgentView 虽然预留了 scrollbar gutter，却没有渲染 scrollbar；picker
仍通过一套整数高度的 `┃` shim 绘制，与 Grok Build 使用的 `tui-scrollbar`
子单元精度、全块 thumb 和 follow-mode 明暗规则不一致。

顶部状态行目前只显示连接、模型、队列和运行状态，没有接入 Harness 已发布的
上下文压力 projection，也没有使用 Grok Build 的右对齐 status item 和
context bar 组件。

## 设计契约和复用依据

- 对应长期计划章节：AgentView render order、Scrollbar、Agent status。
- Grok source commit：`19d42e35c07a9c9244f03f6df0c4c353f970d4f9`；
  SOURCE_REV：`7d67deacbeb1c1093fdb4f9bcbfab2630e18a6aa`。
- Scrollbar 对应源码：
  `crates/codegen/xai-grok-pager-render/src/render/scrollbar.rs` 和
  `crates/codegen/xai-grok-pager/src/views/agent.rs`；复用等级 A1/B。
  生产绘制复用 workspace 已有 `dsh-pager-primitives::scrollbar`，只在
  AgentView adapter 接入 Grok 的主题、超大高度缩放、follow dim 和
  timeline-rail 排他顺序。
- 上下文状态对应源码：`views/context_bar.rs`、`views/progress_bar.rs`、
  `views/agent_status.rs`；复用等级 B。保留 compact token 格式、颜色梯度、
  hover progress、固定宽度和右对齐 separator 布局；排除与该组件无关的
  Grok task/goal runtime。
- DSH-neutral seam：`SessionState.projection("contextPressure")` →
  `ContextUsageSnapshot`。used 优先读取 replay-aware `projectedTokens`，回退
  `pressureTokens`；total 读取正数 `contextWindow`。缺字段时不估算、不展示。
- 不新增协议、Intent、Effect、generation 或 RPC；projection 仍由 Harness
  和 `SessionState` 保持权威。

## 风险、回滚和依赖

- transcript 的 `self.scroll` 是距底部距离，而 scrollbar 需要距顶部 offset；
  接线必须使用已恢复 anchor 后的 `scroll_top`。
- timeline rail 与 scrollbar 共用 gutter，必须严格互斥，避免覆盖。
- header item 需要保持左右内容不碰撞，compact 宽度下省略次要连接详情。
- context projection 可能缺失、为旧版形状或窗口为 0；解析必须失败安全。
- 回滚本记录对应的单一 commit 即可恢复。

### 摘要

- 删除 UI crate 的整数高度 `┃` scrollbar shim，改为 re-export 并复用
  `dsh-pager-primitives` 中从 Grok Build 派生的 `tui-scrollbar` 实现；主
  AgentView 接入 Grok 的 `ScrollInfo`、超大高度缩放、`█` thumb、整 cell
  background fill、主题颜色和 follow-mode 0.4 blend。
- transcript 把 anchor 恢复后的真实 `scroll_top` 作为顶部 offset 交给
  scrollbar；timeline rail 成功计算时不绘制 scrollbar，与上游 render order
  保持互斥。
- B 级移植 Grok `AgentStatusBar`、`context_bar` 和 1/8-cell `progress_bar`
  组件；顶部左侧仍保留 session title，右侧改为可组合、带 ` │ ` separator
  的命名 status item，并把 context item 的精确 Rect 注册到统一 hit map。
- 鼠标移入 context item 后，在相同宽度内从 `used / total` 切换为 progress +
  percentage；移出后恢复 token 数，不发生 header layout shift。
- 新增 `ContextUsageSnapshot` adapter：从 Harness `contextPressure` 读取
  `projectedTokens`，缺失时回退 `pressureTokens`，窗口读取正数
  `contextWindow`；数据不完整时 context 组件不展示，也不从 transcript
  估算。
- SOURCE_MANIFEST 登记三个新 vendor B adaptation 的 upstream/local hash，
  并把 scrollbar、agent status、context bar 的集成状态更新为可审计事实。
- 新增 adapter、component、geometry 和 production semantic-buffer 测试，覆盖
  projection 优先级、token/hover 固定宽度、右对齐 hit rect、scrollbar
  top/bottom/follow/no-overflow，以及 timeline/scrollbar 排他顺序。
