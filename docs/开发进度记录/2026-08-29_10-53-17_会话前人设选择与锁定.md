## 目标与背景

当前 Agent preset 同时暴露为 `/preset`、欢迎页提示和 modal，`Shift+Tab` 又曾被
用于 Plan/permission 语义，入口与锁定时机互相冲突。产品方案重新收敛为：新会话
默认使用 `standard`；首个真实对话开始前可以选择 preset；首个模型 turn 开始后
固定；preset 不属于随时可用的斜杠命令。

本批把入口统一为会话前的 `Shift+Tab` 和 prompt 底边 preset 标签鼠标点击，两者
打开同一个 Grok picker/modal。选择和首次 prompt 之间增加互斥的 pending 状态，
避免 preset recompose 与 turn start 竞态；草稿在打开、取消和选择 preset 时保留。

## 风险、回滚和依赖

- 风险：Host completion 可能先于 control-plane blank 投影；用 session/generation 绑定的
  本地 lock bridge 覆盖这一窗口，最终仍只由 DSH snapshot 收敛。
- 风险：prompt 底边在窄屏被裁剪；hit rect 必须来自实际绘制后的可见 flag rect，不能
  另算一套鼠标坐标。
- 风险：旧 preset completion 跨会话到达；继续使用 operation session/generation guard，
  会话切换时清空仅属于旧会话的 pending UI 状态。
- 回滚：回滚本记录对应的单一 commit；Host/session 数据无需迁移。
- 依赖：当前 profile 提供 `agentPreset.list/select`；空名册时 UI 保持可诊断而不伪造
  可切换能力。
