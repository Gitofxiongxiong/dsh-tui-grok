# 子 agent 详情打开子会话历史

> 记录时间：2026-08-25 18:50:59 +0800
> 操作者/agent：Grok
> 状态：completed

## 目标与背景

PR1 已经让 catalog 进入顶部 pane。双击/Enter 仍打开三行 metadata overlay，
和 Grok 的 child fullscreen 不一致。本批次用 DSH `subagent.history` 把子会话
transcript 填进详情层；Esc/q 只关闭详情，不 interrupt。live mux 观察者和
完整 AgentView fullscreen 留到下一批。

## 设计契约和复用依据

- Grok：Enter/双击打开 child transcript；q/Esc 返回父会话。
- DSH 真源：`subagent.history`，与 Web `openSubagent` 同一 unary。
- 复用：`DshPresentationAdapter::adapt_history` 把 child 事件折成已有
  `TranscriptRow`，不新写一套 renderer。
- 等级 B/C。不改 gateway presentation 过滤，不 attach child 为 driver。

## 计划修改范围

- `crates/dsh-pager-grok-ui/src/host_adapter.rs`：history → transcript 投影、
  `SubagentRow::address`。
- `crates/dsh-pager-grok-ui/src/views/agent_panes.rs`：详情层画 header +
  child transcript，footer 标明 Esc 返回。
- `crates/dsh-pager-grok-ui/src/runtime.rs`：打开 subagent 时 peek history；
  Esc 丢本地 child viewer。
- 本进度记录。

不修改 protocol、vendor、gateway、control_plane。

## 风险、回滚和依赖

- job-only 行的 id 不是 child session id，history 会失败；详情显示明确错误。
- 一次 peek 最多 100 条，没有 live 流。
- 回滚：还原本记录文件。

## 实际实现

- `SubagentRow::address()` 只对真正的 child session 生成 `{parent, child, mode}`；job-only 行拒绝。
- `child_transcript_from_history` 用 `DshPresentationAdapter::adapt_history` 折子会话事件。
- Enter / 双击调用 `subagent.history`，详情层画 header + transcript；Esc/q 关闭详情且文案标明不 cancel。
- 无 address 或 history 失败时显示明确错误，不伪造 child 内容。
