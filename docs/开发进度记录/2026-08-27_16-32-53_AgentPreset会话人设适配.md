# Agent Preset 会话人设适配

> 记录时间：2026-08-27 16:32:53 +0800
> 操作者/agent：Grok
> 状态：completed

## 目标与背景

`dsh-tui-grok` 目前把模型侧工具挂在 host 平面，没有 `dsh-agent-presets` 名册。
用户看到的欢迎页 `mode` 是 Shift+Tab 的 plan/sandbox 循环，不是 DSH 原生的
会话人设（`standard` 标准 / `code` PTC / `minimal` 极简 / `cordis` 创造）。
这些人设必须在每次对话开头选定，并与该会话绑死；已产出 `turn/start` 后锁定。

## 设计契约和复用依据

- 对应长期计划章节：2.3 DSH 真源、2.4 中性 DTO seam、树外插件不得改 Harness。
- Grok source path、commit、SOURCE_REV：继续复用仓库内固定 Grok picker /
  modal_window / AgentView / prompt flags；不新建第二套权限循环。
- 复用等级：B（Grok picker/modal 呈现人设名单）/ C（DSH agentPreset RPC
  与 per-session 组装是 Host 真源）。
- DSH-neutral seam：`GrokHostSnapshot.agent_preset` / `session_blank`；
  `UiIntent::{ListAgentPresets,SelectAgentPreset}` → 公开 ApiProxy
  `agentPreset.list` / `agentPreset.select`；`session.create` 可带
  `agentPreset`。不新增 `tui.setAgentPreset`。
- 组合：`id: agent-presets` 必须是未加作用域的官方 id，以便 CLI
  `profile-boot` 注入随包 `config/agent-presets/`。host 平面模型工具行
  `disabled: true`，与官方 web-app / dsh-TUI 同一份清单。
- 失败测试、PTY/golden 和回滚：bundle patch 断言、effect 编码、slash、
  welcome 文案、resume picker 不再把 preset 塞进 `model_id`。回滚即还原
  本记录列出的文件。

## 风险、回滚和依赖

- 风险：禁用 host 工具后若名册未挂上，所有会话会没有模型工具。缓解：
  `id: agent-presets` 与 CLI profile-boot 对齐，bundle 测试锁定该行。
- 风险：`agentPreset.select` 成功后 control plane 可能晚一拍。缓解：
  UI 保留 `pending_agent_preset`，对齐已有 session mode pending。
- 风险：`Ctrl+N` 在当前 shell 是 prompt 历史，不抢占；新对话走 `/new`。
- 回滚：还原本记录文件，去掉名册行即回到 host 平面工具。
- 依赖：已发布的 `@deepseek-ai/dsh-agent-presets` 与
  `@deepseek-ai/dsh-cordis-host-runner` 0.1.0-rc.8；公开 ApiProxy
  `agentPreset.*` / `session.create.agentPreset`。

## 实际修改

- 组合：`tui-embedded` 与 `runtime` 的 `cordis.patch.yml` 挂上 `id: agent-presets`、
  `cordis-host-runner`，并禁用 dsh-base 上的模型侧工具行；package 依赖对齐
  `dsh-agent-presets` / `dsh-cordis-host-runner` 0.1.0-rc.8。
- 协议/loader：`AgentPresetListValue` / `select` / `create_blank_session` /
  `list_agent_presets` / `select_agent_preset`。
- UI：欢迎页展示人设；`/preset` picker；`/preset <id>` 空白可切、开跑锁定；
  `/new` 建空白会话。Shift+Tab 仍是 plan/sandbox。
- resume picker 的 `model_id` 恢复为模型；人设走独立 `agent_preset` 字段。
