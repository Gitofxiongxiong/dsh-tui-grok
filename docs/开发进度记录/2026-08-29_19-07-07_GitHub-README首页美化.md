## 目标与背景

当前根 README 以内部架构、开发脚本和本机接线细节开场，虽然信息真实，但访客
无法在首屏快速回答“项目有什么用、如何安装、现在能做什么”。本批次把 README
重构为面向用户的产品首页：突出一句话价值、真实 TUI 画面、npm 快速安装、核心
能力、平台兼容性和清晰的反馈/Star 入口，同时保留架构、开发与许可证信息。

GitHub 仓库当前公开但 About 描述、topics、homepage 和 social preview 均为空；
这些属于仓库元数据，不在本批次改动范围。README 不能保证获得 Star，本批次只
降低理解和试用门槛，并为后续分发提供可复用首页。

  徽章、单命令安装、短能力列表、多语言入口和明确社区链接。
