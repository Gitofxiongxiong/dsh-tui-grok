风险是 ratatui/crossterm 版本差异和旧 fallback 测试耦合。实现保持现有公开入口

## 实际修改

- `crates/dsh-grok-inline/src/terminal.rs` 增加 Grok-derived `draw_with_links`，
  将 link map 与 cell diff/cursor/flush 接到 surface。
- `crates/dsh-pager-render/src/lib.rs` 收归 semantic Theme，增加
  `TerminalCapabilities`、显式 capability fallback、resize epoch/sync、条件
  raw/alternate/mouse/paste/cursor 生命周期和 OSC52 unsupported receipt。
- `crates/dsh-pager-grok-ui/src/theme.rs` 改为 renderer Theme re-export；
  `src/app.rs` 增加 AppShell、KeyOwner、overlay、Esc ladder、adaptive layout、
  replacement map 和 focus/overlay semantic snapshot。
- `src/runtime.rs` 改用 AppShell 统一处理 key/mouse/paste/resize/tick/notification，
  使用 grapheme-aware prompt viewport/cursor，删除 picker_open 平行状态。
- `src/lib.rs` 导出 shell、theme 和 terminal capability seam。
