## 目标与背景

N1-N3 的 capability/controller 与 production pane adapter 已完成。最后一批先修
reference runner 只把 prompt buffer 纳入 `SemanticFrame.cells` 的缺口，令 cell
oracle 覆盖完整 terminal buffer、header/transcript/panes/prompt/footer，再执行
完整 workspace、协议、source provenance、parity、PTY 和 E2E 门禁。

## 设计契约和复用依据

- semantic cell 仍比较稳定 color roles，不比较 ANSI；capture area 必须是完整
  terminal `Rect`，不能只截 prompt 子矩形。
- reference fixture 只构造 DTO/Buffer，不引入 Grok agent runtime；production
  side effects 仍走 `UiIntent -> UiEffect -> receipt`。
- N2 的 `ScrollbackPane` 保持 production 唯一 scroll geometry；parity 中保留
  RichTranscript 作为 deterministic reference oracle，不再被 runtime 调用。

## 计划修改范围

- `crates/dsh-pager-grok-ui/src/parity.rs`：完整 buffer semantic-cell capture、
  role styles 和 full-screen tests。
- 本记录文件：收尾回写。

## 风险、回滚和依赖

- 风险：full-area capture 会改变历史 snapshot 的 cell 坐标；同步更新契约测试，
  不弱化比较范围。
- 风险：fallback 不能伪装成 available；运行所有 capability/e2e fixture 检查
  pending/unsupported 文案和无效 RPC 防线。
- 回滚：回退本记录单一 commit，保留 N1-N3 controller commits。

## 实际修改

- `ReferenceRunner` 现在先建立完整 terminal-area Buffer，填充 header/transcript/
  task/catalog/queue/footer semantic rows，再在同一 Buffer 上绘制 Grok prompt
  widget；`SemanticFrame.cells` 覆盖整个 `width × height`，不再只捕获 prompt
  子矩形。
- 新增 semantic row role 样式映射和 full-frame coordinate/cell-count 测试；
  颜色仍按 Theme role 序列化，避免 RGB profile 偶然差异。
- 保留真正 unsupported 的 Kitty/iTerm image escape 为显式 metadata/fallback，
  不把无 backend capability 的 loaded preview 当成功；runtime 仍只通过
  `ScrollbackPane` 绘制 production transcript。
