## 实际文件与摘要

- B1：`scripts/pack-native.mjs` / `scripts/verify-runtime-pack.mjs` 用
  `process.execPath` + `npm/bin/npm-cli.js`（相对 node 前缀回退），拒绝 PATH `npm`。
- B2：五个 native `files` 含 LICENSE-MIT / LICENSE-APACHE / NOTICE；pack 时从仓库根复制。
  `.gitignore` 不入库这些副本。`verify-native-matrix.mjs` 检查 `files`。
- B3：runtime 钉死 `@deepseek-ai/cordis` `4.0.1`、`@deepseek-ai/schemastery` `3.18.1`；
  pack 校验与 runtime 单测同步；`pnpm-lock.yaml` importer specifier 同步。
- I1：release 无 `--backend` 且未设 `DSH_TUI_SERVER` 时拒绝 PATH `dsh`，除非
  `debug_assertions` 或 `DSH_PAGER_DEV_MODE=1`。
- I2：`DSH_TUI_SERVER` trim；空白 → CLI/Rust usage 退出 2。
- I3：RPC timeout / disconnect / pump disconnect / stdin write 失败走 `mark_failed`，Drop 打 stderr tail。
- I4：`capture_cli` 在等待子进程时线程排空 stdout。
- I5：CI 增加 Ubuntu `pnpm install --frozen-lockfile` + `pnpm run verify:ts`。
- I6：pack 后 `tar -tvf` 检查 Unix 二进制可执行位和许可证文件。
- I7：四个 `dsh-tui-*` `private: true`，去掉 public `publishConfig`。
- I8：doctor 缺 native / 解析失败 `hardFail = true`。
- I9：`DSH_PAGER_BIN` 仅当 `DSH_PAGER_DEV_MODE=1`。
- I10：gateway 读不到包版本即 throw，不再 `'0.0.0'`。
- S5：四份 2026-08-26 进度记录去掉多余 EOF 空行。
