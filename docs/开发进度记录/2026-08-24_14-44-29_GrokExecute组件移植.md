### 摘要

- 将上游同名 `ExecuteToolCallBlock` 以 B 级结构性适配移入 vendor。组件拥有 `Collapsed/Truncated/Expanded`、description-first `Run` header、secondary `$ command`、output panel、head/tail truncation、success/running/error accent、foldability、agent/bash finish-mode 规则。
- 保留 7 个 Execute 组件测试，覆盖折叠隐藏命令、展开 header/command/panel、截断、Run/Running 去重、foldability、finish mode 和 accent。
- 新增 `execute_tool_adapter.rs` 作为唯一 DSH seam：terminal card 使用 `title/description/output`，generic execute 使用 string `rawInput`、call content description 和 generic result content；vendor 文件不引用 `dsh_pager` 或 Harness RPC。
- transcript 的 collapsed 行直接消费 `ExecuteToolCallBlock::output(Collapsed)` spans；expanded 行直接消费 `output(Expanded)` 的 header、command、separator 和 panel metadata。删除原有 terminal cwd/exit/command/output 手工拼装和 generic execute 特判。
- entry chevron/rail 仍由 scrollback wrapper 添加，符合 Grok 的 Execute block 与 EntryRenderer 分工；双击 hit-map/display-mode 状态机保持不变。
- SOURCE_MANIFEST 新增上游 hash `82f28d...b6d15` 和 vendored hash `536a35...c52a`，明确记录 AppearanceConfig、BlockContent selection range、VTE、permission/syntect closure 尚未移植，未虚假标为 A0。
- 主计划修正为实际组件所有权，并移除上一批对 cwd/成功 exit code 的本地扩展声明。
