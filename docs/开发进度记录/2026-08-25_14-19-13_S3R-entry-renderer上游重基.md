## 目标与背景

- 以固定 Grok Build `scrollback/layout.rs` 与 `wrappers/entry_renderer.rs` 为
  production 基线，替换当前 182 行 line-postprocess mini renderer。
- 闭合 S3 必需的 layout padding、Buffer 直绘、pending-input freeze、整块 timestamp
  reserve、clipped `skip_rows`、group header、accent/bullet 同步和 finish flash。
- DSH 继续拥有历史 identity/Fenwick/anchor；renderer 消费 renderer-neutral projected
  entry，不引入 Grok ScrollbackState/session runtime。

## 风险、回滚和依赖

- timestamp/right padding 改成上游几何后会改变 wrap/height；Fenwick 高度、hit-map
  和 copy 必须由同一 Buffer projection 回报，不能保留旧 Paragraph 宽度算法。
- partially visible entry 必须把 `skip_rows` 加进 rail logical row，避免滚动时行波跳相。
- pending-input 真源必须从 DSH interaction/call identity 投影，不能由 renderer 猜。
- 回滚按新 renderer module 与 production 调用点逐项恢复；不执行 reset/checkout。

## 实际修改

- A0 复制上游 `scrollback/layout.rs`，production chrome width 改用上游
  accent + left pad + content + right pad 结构；默认总 chrome 从本地 3 列纠正为
  上游 5 列，selectable content offset 保持 accent + left pad 的 3 列。
- EntryRenderer B seam 改读上游 `LayoutConfig`，使用 Grok glyph registry 接缝，
  增加 pending-user-input 对 animated rail/bullet 的静态冻结。
- timestamp 宽度改为整块一致预留，不再只有首个 selectable semantic row 减 10 列；
  hit-map 使用 renderer 返回的实际 content width。
- clipped viewport 继续使用 entry 内 `accent_wave_row`，动态 paint 不以 visible row
  重置相位。
- host interaction 通过 call id 投影到对应 tool entry；question 无 call id 时回退到
  最新 running tool/thinking/assistant entry。renderer 不读取 RPC/SessionState。
- SOURCE_MANIFEST 新增 A0 layout 行并更新 EntryRenderer/glyphs 来源说明与 hash。
